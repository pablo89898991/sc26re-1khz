SC2 Remapper

Map every Steam Controller (2026) input — buttons, back buttons L4/L5/R4/R5, trigger clicks, stick / trackpad / grip touch, sticks and trackpads — to keyboard, mouse and Steam pad buttons. Profiles live in the controller: it works without Steam and without installing anything, over cable and the Puck. Needs sc26re firmware v51+ and desktop Chrome / Edge / Brave (WebHID).

Controller

not connected
On the controller: LB + RB + Menu turns the remapper on/off (high beep = on). While it is on, every mapped input belongs to it: Steam and the game only see what it is mapped to. Unmapped inputs work as usual.

Click an input on the controller or in the lists to edit it. Press: actions while held (up to 4 at once, e.g. Ctrl + C). Hold: a second set when held longer than 0.25 s (a short press then taps the first set). Double: a set on a second quick press. Toggle: the first set switches on/off with each press. Inputs light up green while you press them.

Gyro and gyro as mouse

The same settings as in the report meter (they are controller-wide, not per profile). Apply = until power-off, Save = kept. Gyro as mouse on/off on the controller: LB + RB + View (off after every power-on). While it is on, no program gets the gyro.

Gyro tools

360° calibration (per game): in the game look at something you can find again, press start (or LB + RB + View + A), then the calibration button (or start turn) — the camera turns slowly — and press it again when it has done exactly 360°.
