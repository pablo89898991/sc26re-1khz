Controller-wide (not per profile) — the same settings as in the report meter. Apply = until power-off, Save = kept.

What it is

Profiles stored in the controller turn its inputs into keyboard keys, mouse buttons / movement / scroll and Steam pad buttons. It works without Steam and without installing anything, over the USB cable and the Puck. Needs sc26re firmware v51+ and desktop Chrome, Edge or Brave.

Turning it on

LB + RB + Menu on the controller (high beep = on, low = off) or the Remapper switch at the top. While it is on, every input that has a binding belongs to the remapper: Steam and the game only see what it is mapped to. Inputs without a binding work as usual.

Binding an input

Click it on the picture or in the lists. Press = actions while held (up to 4 at once, e.g. Ctrl + C). Hold adds a second set for holding longer than 0.25 s (a short press then taps the first set). Double adds a set for a quick second press. Toggle switches the first set on/off with each press. Then press Save to controller.

Sticks and trackpads

Each one can stay with Steam, act as 4 directions (each bound like a button), move the mouse or scroll. Touch sensors (stick touch = capsense, grip touch = gripsense, trackpad touch) and trackpad clicks are bindable like buttons.

Profiles

4 profiles. Choose the active one with Steam + D-pad on the controller (up = 1, right = 2, down = 3, left = 4; the beep gets higher with the number), at the top of “Buttons & profiles”, or with a “Switch to profile” action bound to any input. Export / Import saves a profile to a file.

Gyro

Gyro settings and gyro as mouse (on/off: LB + RB + View) are on the “Gyro & gyro mouse” page; they are the same for every profile.
