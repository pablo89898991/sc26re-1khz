SC2 firmware test p.2026-11-19a

Needs a test build (v51 test 59 or newer). Checks the firmware itself, not only the remapper: every setting (range, clamping, “auto”), report rates, the gyro / accelerometer at every range and rate (timestamps, sample rate, noise at rest), the settings channel under load, the pad report the firmware builds from known inputs, and the diagnostics it reports. Settings are changed live only (never saved) and put back. Leave the controller lying still; Steam can stay open (the pad report part sends sticks and triggers to it for a few seconds).
