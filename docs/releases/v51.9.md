## Changed: the accelerometer with the gyro

In v51.8 the tick box "off while the gyro mouse / joystick is on" switched the accelerometer off **all the time the gyro mouse was on**, so with the gyro mouse switched on (for example activated by touching the right stick) gestures and tilt never worked. It is now a choice, **With the gyro**, in the remapper's Accelerometer entry, per profile, for gestures and tilt (stick and buttons):

- **always works**: the accelerometer works also while you aim with the gyro.
- **off while the gyro aims** (the default when you bind the accelerometer): off only while the gyro's activation is held, for example while your thumb is on the stick. Thumb off the stick: gestures and tilt work. With activation "always" the gyro aims all the time it is on, so the accelerometer is off then.
- **off while the gyro aims, works with "always"**: the same, but with activation "always" the accelerometer keeps working.

With the gyro mouse off or not set up, the accelerometer always works. Profiles saved with v51.8's tick box get "off while the gyro aims"; profiles without it get "always works", as before.

## Remapper page (already live)

- **Load from Steam**: paste a Steam Input community layout link (`steam://controllerconfig/...`) and the layout is loaded into the profile; "Save .vdf" keeps the file too. Also in SC2 Overlay 1.5.
- **Keep controller on**: while the remapper page is connected, the controller does not switch itself off (as in the report meter).

## Tested on a controller

- The three settings by hand: shake with the thumb on and off the stick (gyro mouse activated by touching it), all as described above.
- 229 remapper cases, 100 random profiles and 11 diagnostic cases: the same as the simulator apart from a few that differ by a millisecond or so at a step edge, and the same as v51.8 on the same controller under the same conditions.
- Firmware test page: 172 of 172. Gyro regression: 25 of 25. Accelerometer: 26 of 26 test cases (16 from v51.8 and 10 for the new setting), and no false gestures on a still controller.

## Under the hood

- `sc26re/acc/<profile>` flags: 0x80 = off while the gyro aims, 0x80 | 0x40 = the same but works with "always" activation.
