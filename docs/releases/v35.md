Custom Steam Controller (2026) firmware with **1000 Hz** reports and the 1 kHz IMU path, based on Valve's latest stock firmware **6AE90BC5**.

**Download:** `SC26RE_1k.fw`. `SC26RE_1k_puck_dbg.fw` is the same build with Puck link counters in the quaternion fields. Flash it with Ibex Web Utilities or `flash.py`. The report meter and the Puck patcher are on the [SC2 1 kHz tools](https://pablo89898991.github.io/sc26re-1khz/) page.

## Changes since v34

### Drop easter egg: Wilhelm scream / meow (new)
- **When it plays:** if the controller falls, it plays either the Wilhelm scream or a meow, 50/50, on **both grips**.
  - Stock plays it on the left grip only, with about 19% scream, 31% meow and silence the rest of the time.
- **Same sounds as stock:** both samples are the exact ones from stock firmware. The meow sample (stock haptic script 17) was missing in sc26re until now.
- **How a fall is detected:** acceleration below 0.156 g for 260 ms. The controller then needs normal acceleration again before the next fall counts, and there is a 2 s cooldown between sounds.
- **When it works:** only while the motion sensor is running, i.e. when Steam uses gyro (Big Picture or a game with gyro). Stock behaves the same way.
- **Build options:** the chances and the fall time can be changed at build time: `CONFIG_IBEX_DROP_SCREAM_PERCENT`, `CONFIG_IBEX_DROP_MEOW_PERCENT`, `CONFIG_IBEX_DROP_FREE_FALL_MS`. `CONFIG_IBEX_DROP_SCREAM=n` turns the feature off.
- **Smaller firmware:** both samples are stored in stock's 8-bit μ-law format. This is lossless compared to stock and uses half the flash.

### More stock system sounds
All of these play on the grips at the power-chime level (`user/haptic_boot_level`).

- **Power-on chime by connection:**
  - USB, Puck slot 1 or Bluetooth slot 1: rising 588 → 699 → 882 Hz chime.
  - The second Puck or Bluetooth slot: the same chime with an extra high note at the end.
  - Like stock, it also plays after reboots that continue in wireless mode.
- **Bluetooth pairing started** (RB + A + B at power-on): a rising four-note chime.
- **Paired** (Bluetooth bond, or a Puck pairing saved by Steam): the same four notes falling.

### Trackpads
- **Stock position filter.** Setting 65 `trackpad_filt_ctrl` is on by default in stock and is now implemented. It is the same One Euro filter with the same parameters as stock (min cutoff 0.001 Hz, beta 0.1, derivative cutoff 1.2 Hz). The finger position is steady when you hold still or move slowly, with almost no lag on fast moves.
  - Stock assumes a fixed 250 Hz trackpad rate. sc26re uses the measured trackpad rate instead.

### Connection mode
- **Boot chords save the mode at once.** Choosing Puck (RB + A) or Bluetooth (RB + B) at power-on is now saved immediately. Before, it was saved only after 1 minute of running, so turning the controller off sooner brought back the old mode.

### Steam settings check
I compared all 35 settings that stock firmware actually uses with sc26re. All default values match stock.

- **Filled in now:** the trackpad filter described above.
- **Still missing, no effect in normal use:** Steam never turns these on, and they are off by default in stock: trackpad rotation, stabilizer, pressure mode, raw joysticks, LED colour override.
