A small update to [v51](https://github.com/pablo89898991/sc26re-1khz/releases/tag/v51). Flash `SC26RE_1k.fw` with the report meter's flasher; your settings and profiles are kept.

## New

- **IMU mode switch.** The controller's sensor (ST LSM6DSV16X) can run in **high-accuracy ODR** mode, the default and the same as before (exactly 2000 / 4000 / 8000 Hz), or in **high-performance** mode (1920 / 3840 / 7680 Hz). Set it in the remapper (*Gyro & gyro mouse → Gyro sensor → Sensor mode*) or in the report meter (*IMU mode*). It applies at once, with no restart. The setting moves the accelerometer and the gyro together, without a break in the reports. On the test controller the noise at rest was the same in both modes.
- **The tools work offline.** After you open the tools page once, Chrome / Edge keep every page, the 3D models and the scripts, so the same address opens without the internet. The tools can also be installed as an app with their own window: use the install icon at the right of the address bar.
- **[SC2 Overlay 1.1](https://github.com/pablo89898991/sc26re-1khz/releases/tag/overlay-v1.1.0)** (Windows app) now has every tool inside: the remapper, the report meter with the flasher, the 3D overlay page and the Puck patcher, offline, from the tray icon.

## Fixes

- **Remapper:** a settings request that gets no answer no longer stalls the page. In the overlay app the remapper stayed at "waiting for the controller" and Reload did nothing.
