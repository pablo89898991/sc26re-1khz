Custom Steam Controller (2026) firmware with **1000 Hz** reports and the 1 kHz IMU path, based on Valve's latest stock firmware **6AE90BC5**.

**Download:** `SC26RE_1k.fw`. `SC26RE_1k_puck_dbg.fw` is the same build with Puck link counters in the quaternion fields. Flash either one with Ibex Web Utilities or `flash.py`. The report meter and the Puck patcher are on the [SC2 1 kHz tools](https://pablo89898991.github.io/sc26re-1khz/) page.

## Changes since v38

### Forgetting a Puck pairing works
In Steam, forgetting the controller's Puck connection did nothing. The controller kept its pairing and reconnected to the same Puck.

- **Cause:** Steam forgets a pairing by deleting the setting that stores it: `esb/bond` for slot 1, `esb/bond_2` for slot 2. sc26re did not support the delete command (`DELETE_SETTING`, 0xF0). It answered "not supported" and kept the pairing.
- **Fix:** sc26re now handles the delete command:
  - It erases the pairing for that slot from flash and from memory.
  - If that slot was the active wireless connection, the controller switches to its other paired Puck if there is one, or to no Puck. The link drops and the controller stops reconnecting to the forgotten Puck.
  - To use the Puck again, pair it the normal way.
- **Logging:** the delete command now shows up in the controller log as `delete setting …`.
