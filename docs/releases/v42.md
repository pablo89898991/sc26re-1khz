Custom Steam Controller (2026) firmware with **1000 Hz** reports and the 1 kHz IMU path, based on Valve's latest stock firmware **6AE90BC5**.

**Download:** `SC26RE_1k.fw` is the firmware to use. Two diagnostic variants are also attached:
- `SC26RE_1k_capsense_dbg.fw`: raw stick/grip capsense values in the quaternion fields, for tuning.
- `SC26RE_1k_puck_dbg.fw`: Puck link counters in the quaternion fields.

Flash with Ibex Web Utilities or `flash.py`. The report meter is on the [SC2 1 kHz tools](https://pablo89898991.github.io/sc26re-1khz/) page.

## Changes since v41

### Live settings in the report meter
A new **"Live settings"** panel changes the controller's behaviour on the fly, without reflashing:
- **Read all:** shows the current values.
- **Apply changes:** applies immediately, until the controller is switched off.
- **Save:** keeps the values after power-off.
- **All defaults:** returns everything to the defaults; a hard reset does the same.

Settings that Steam normally sends have a **"Steam"** box. When it is ticked, the controller follows Steam as before. Entering a number overrides Steam, and Steam will not overwrite it.

| Setting | Range / default |
|---|---|
| Trigger click point | 40–99 % of travel (default: Steam's value) |
| Trigger released dead zone | 0–30 % (default 8 %) |
| Trigger smoothing | 0 = off … 4 (default 2) |
| Report rate | 1000 / 500 / 250 Hz (button changes always go out instantly) |
| Gyro dead zone | raw units (default: Steam's value) |
| Gyro smoothing | 0 = off … 4 (default off) |
| Trackpad smoothing | 0 = off, 5 = stock, 10 = smoothest (default: Steam's on/off) |
| Trackpad click pressure | default: Steam's value |
| Trackpad noise threshold | default: Steam's value |
| Haptics volume | −24 … +6 dB (default: Steam's value) |
| Drop: scream / meow chance | % per drop (default 50 / 50; both 0 = silent) |
| Stick touch on / off (capsense) | raw units (default 720 / 80 % of on) |
| Grip touch on (gripsense) | raw units (default 900) |
| LED brightness | % (default: Steam's value) |
| Auto power-off | minutes without input, 0 = never (default: Steam's value) |

The capsense thresholds from v41 moved into this table.

**Tools in the same panel:**
- **Calibrate gyro:** put the controller on a table, wait 3 s without touching it, then press. It uses the same calibration as Steam.
- **Zero sticks (save):** take your hands off both sticks and press. Each stick's resting point becomes its centre; the full range is unchanged.
- **Power-on chime:** off / quiet / normal.

### Puck pairing storage fixed
- **The problem:** v40 and v41 stored a forgotten Puck slot as an all-zero record. Steam could read that record as a pairing with an unknown Puck.
- **What changed:** a forgotten slot is now deleted again, as before v40. A separate marker keeps the old stock pairing from coming back after a reboot.
- **Cleanup:** all-zero records left by v40/v41 are cleaned up automatically on the first start.

**Known issue:** on some setups Steam may still ask to pair the controller with the Puck again after flashing. Pairing once fixes it until the next flash.
