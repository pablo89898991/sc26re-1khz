Custom Steam Controller (2026) firmware with **1000 Hz** reports and the 1 kHz IMU path, based on Valve's latest stock firmware **6AE90BC5**.

**Download:** `SC26RE_1k.fw` is the firmware to use. Also attached:
- `SC26RE_1k_capsense_dbg.fw`: raw stick/grip capsense values in the quaternion fields, for tuning.
- `SC26RE_1k_puck_dbg.fw`: Puck link counters in the quaternion fields.

**How to flash:** use the flasher in the report meter so that your pairings and settings survive. Close Steam first, connect by cable and keep "keep settings" ticked. The report meter is on the [SC2 1 kHz tools](https://pablo89898991.github.io/sc26re-1khz/) page; refresh it (Ctrl+F5) after updating.

## Changes since v48

### New: gyro as mouse (like Alpakka)
The controller can turn the gyro into mouse movement itself. Everything else stays a normal Steam controller. Set it up in the new **Gyro as mouse** panel of the report meter.

- **No built-in dead zone.** The raw gyro (drift removed) is used, and fractions of a count are carried over to the next report (sub-pixel accumulation), so slow turns are not lost. Optional per-axis dead bands (hard or soft) can be copied from "Gyro at rest".
- **On/off on the controller: LB + RB + View** (high beep = on, low = off), or the button in the meter. While the three buttons are held, the game does not see them.
- **Activation:** any button or touch sensor (grips, stick touch, trackpad touch or click, triggers…), with *hold to turn on*, *hold to turn off*, *press to toggle* or *always on*. Default: hold a touch on the right trackpad.
- **Axes:** pitch, yaw and roll can each move the cursor horizontally, vertically or not at all, optionally inverted. Yaw + roll together on the horizontal axis works too.
- **Real world sensitivity:** 1.00 = turning the controller 90° turns the camera 90°. Per-axis sensitivity in % on top (e.g. roll 88 %).
- **360° calibration per game:** LB + RB + View + A (or the meter button). Press the calibration button (default A): the camera turns slowly. Press it again when it has done exactly 360°, and the count is saved. It can also be typed in.
- **While it is on, no program gets the gyro.** The pad report carries no motion data, so Steam cannot move the camera a second time.
- **Works over cable, Puck and Bluetooth.**
  - Cable: the mouse shares USB frames with the pad (mouse priority while moving, or 500/500).
  - Puck: 500 mouse reports/s by default. The Puck sends mouse and pad through the same USB endpoint, so the controller never puts both into one radio packet. Measured with the meter's link test: ~5 % difference between sent and received counts over the Puck vs ~3 % over cable (that much is test error). Before this fix about a third of the movement was lost.
- **Mouse link test** in the meter: compares the counts the controller sent with what the PC received.

### Steam + Y powers the controller off
Hold Steam + Y for half a second. Y is hidden from the game while Steam is held. Holding Steam alone still works as before.

### Gyro sample rate in the sensor
New Live setting: 2000 (default), 4000 or 8000 Hz. In our measurements it made no real difference to noise; the sensor's hardware filter does, so 2000 + filter 1 stays the default.

### Gyro calibration fixes
- **Full gyro calibration and Calibrate gyro no longer fail at the end.** Saving waited for the sensor's FIFO to restart, which can now take longer than 1 s; that threw the new calibration away. It is now saved either way.
- The "at rest" check allows up to 8 °/s (was 5 °/s), because at 2 kHz a resting controller already shows spikes around 4 °/s.
- When it fails, the meter now says why: which button or touch sensor was active, that the gyro moved, that no gyro data arrived, or that saving failed.

### Report meter
- **Save stores everything:** all Live settings and the gyro mouse settings. Before, Save after Apply skipped the capsense thresholds, so they came back as defaults after a restart.
- **Auto-refresh (3 s)** of the shown values. It pauses while you edit.
- The controller list names the **USB cable** and the **Puck slots**.
