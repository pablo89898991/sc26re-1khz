Custom Steam Controller (2026) firmware with **1000 Hz** reports and the 1 kHz IMU path, based on Valve's latest stock firmware **6AE90BC5**.

**Download:** `SC26RE_1k.fw` is the firmware to use. Also attached:
- `SC26RE_1k_capsense_dbg.fw`: raw stick/grip capsense values in the quaternion fields, for tuning.
- `SC26RE_1k_puck_dbg.fw`: Puck link counters in the quaternion fields.

Flash with Ibex Web Utilities or `flash.py`. The report meter is on the [SC2 1 kHz tools](https://pablo89898991.github.io/sc26re-1khz/) page; refresh it (Ctrl+F5) after updating.

## Changes since v44

### "Reset gyro calibration" in the report meter
A new button in **Live settings → Tools** removes your gyro calibration. It asks for confirmation first.

**What it resets:**
- **Gyro drift:** the saved drift goes back to the **factory value from Valve's storage**, or 0 if there is none. It applies immediately, no restart needed.
- **Dead bands:** the **pitch / yaw / roll dead bands are switched off** (set to 0 and saved).

**What it leaves alone:** the general gyro dead zone, gyro smoothing, the auto-calibration setting, stick/trigger calibration, pairings and all other settings. It is a hard reset for the gyro only.

If the drift comes back after the reset, run **Full gyro calibration** (LB + RB + X + Y for 3 s, or the meter button). With auto calibration on, simply putting the controller down also corrects it.
