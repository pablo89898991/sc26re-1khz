A small update to [v51.1](https://github.com/pablo89898991/sc26re-1khz/releases/tag/v51.1). Flash `SC26RE_1k.fw` with the report meter's flasher; your settings and profiles are kept.

## Fixes

- **Gyro mouse no longer freezes now and then.** About once every 10–20 minutes the camera could stop for a moment. The automatic gyro calibration started after 3 s with no button or touch, without checking the sticks and triggers, so it could start mid-game, and it paused the gyro mouse while it measured. Now it starts only when the controller is really put down (sticks centred, triggers released), runs in the background without pausing the gyro mouse, stops as soon as the controller turns, and ignores a result that looks like a slow turn rather than drift. The calibrations you start yourself (Steam + X, Steam + A, report meter) work as before.

## New

- **Version check.** The controller now tells which release it runs, so **[SC2 Overlay 1.2](https://github.com/pablo89898991/sc26re-1khz/releases/tag/overlay-v1.2.0)** (Windows and Linux) can tell you when a new firmware or a new app version is out.
