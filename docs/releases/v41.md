Custom Steam Controller (2026) firmware with **1000 Hz** reports and the 1 kHz IMU path, based on Valve's latest stock firmware **6AE90BC5**.

**Download:**
- `SC26RE_1k.fw`: the firmware to use.
- `SC26RE_1k_capsense_dbg.fw`: same, with raw stick and grip capsense values in the quaternion fields. Use it for tuning; gyro aiming in games does not work properly on it.
- `SC26RE_1k_puck_dbg.fw`: same, with Puck link counters in the quaternion fields.

Flash with Ibex Web Utilities or `flash.py`. The report meter is on the [SC2 1 kHz tools](https://pablo89898991.github.io/sc26re-1khz/) page.

## Changes since v40

### Capsense thresholds adjustable live from the report meter
The report meter has a new **"Capsense thresholds"** panel with three settings, all in raw sensor units:

| Setting | What it does | Default |
|---|---|---|
| **Stick touch on** | Value at which a thumb on the stick counts as a touch | 720 |
| **Stick touch off** | Value below which the touch ends (0 = 80 % of "on") | 576 |
| **Grip touch on** | Grip touch threshold; grip release stays a percentage of it | 900 |

Higher = less sensitive (a finger hovering over the stick no longer counts as a touch).

Buttons:
- **Read:** shows the current values.
- **Apply (live):** the new values work immediately, until the controller is switched off.
- **Save:** keeps the values after power-off.
- **Defaults:** returns to the values above. A hard reset also returns to the defaults.

**How to tune:**
1. Flash `SC26RE_1k_capsense_dbg.fw`, open the report meter with Steam closed, click Connect, and pick **"Raw capsense"** under "Quaternion fields show".
2. The raw stick and grip values are shown live, with the current threshold marked on each bar.
3. Set the thresholds, press **Apply** to try them, then **Save**.
4. Flash the normal `SC26RE_1k.fw` again. Saved thresholds are kept.

### Releases now include the capsense tuning build
`SC26RE_1k_capsense_dbg.fw` is now built and published with every release.
