Custom Steam Controller (2026) firmware with **1000 Hz** reports and the 1 kHz IMU path, based on Valve's latest stock firmware **6AE90BC5**.

**Download:** `SC26RE_1k.fw` is the firmware to use. Also attached:
- `SC26RE_1k_capsense_dbg.fw`: raw stick/grip capsense values in the quaternion fields, for tuning.
- `SC26RE_1k_puck_dbg.fw`: Puck link counters in the quaternion fields.

**How to flash:** use the new flasher in the report meter (see below) so that your pairings and settings survive. Ibex Web Utilities and `flash.py` still work, but they wipe sc26re's settings. The report meter is on the [SC2 1 kHz tools](https://pablo89898991.github.io/sc26re-1khz/) page; refresh it (Ctrl+F5) after updating.

## Changes since v45

### Firmware flasher in the report meter: no more re-pairing after updates
Every update used to wipe the controller's sc26re storage, so Steam asked to pair the controller with the Puck again and your calibrations and Live settings were gone. The new **Flash firmware (USB cable)** panel in the meter flashes a `.fw` file like Ibex Web Utilities, but it **keeps your settings**:

1. It saves the storage first: Puck/Bluetooth pairings, calibrations, Live settings. A copy is also downloaded as `sc26re-settings-backup-….bin`, just in case.
2. It switches the controller to its bootloader and writes the firmware.
3. It writes your settings back and restarts the controller.

**How to use it:**
- **Close Steam completely** (tray icon → Exit). The flasher refuses to start while Steam is talking to the controller. Shift + click on Flash skips this check if it ever misfires.
- Connect the controller **by cable**, pick the `.fw` file and press **Flash**.
- The first time, the browser may ask you to pick the bootloader port.
- After the restart most browsers need one more click to see the controller again: press the highlighted **Reconnect & restore settings** button and pick the controller. Wait for "done — settings restored".
- **Restore settings** also works on its own, with a backup `.bin` file.

Desktop Chrome, Edge or Brave (WebHID + Web Serial). This works from v46 onwards: when you flash *from* an older version there is nothing to save, so pair once more this time.

### LB + RB + X + Y: choose what it does
In **Live settings → Tools** you can pick what holding LB + RB + X + Y for 3 s does:
- **Full calibration** (default): the 5-step routine. It sets the pitch / yaw / roll dead bands and the drift, about 15 s.
- **Drift only**: a single drift calibration, about 2 s, with the same purple LED and sounds. The dead bands are left as they are.

The meter's "Full gyro calibration" button always runs the full routine.

### Controller powers off when the Puck / PC is gone
Previously the controller stayed on after you shut down the PC and cut power to the Puck. Now it switches off after **5 minutes** without a wireless connection. Change it with **Live settings → "Power off when the Puck/BT host is gone"** (minutes; 0 = never).

### Triggers no longer keep the controller awake
In some Steam trigger modes the raw trigger value never reads exactly 0, so the firmware treated the triggers as pressed and auto power-off never happened. Now a trigger only counts as active above 5 % after sc26re's calibration.

### Gyro dead bands: hard or soft
New Live setting **"Gyro dead bands: hard / soft"**:
- **0 = hard** (as before): inside the band the gyro reads 0, outside it the full value passes. There is a tiny jump at the edge.
- **1 = soft**: the movement starts from 0 at the band's edge. There is no jump, and very slow movements are slightly weaker.

### Meter fixes
- The meter no longer shows "Infinity" when no reports are coming in.
- After the controller reconnects, its reports are no longer counted twice.
