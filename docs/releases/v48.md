Custom Steam Controller (2026) firmware with **1000 Hz** reports and the 1 kHz IMU path, based on Valve's latest stock firmware **6AE90BC5**.

**Download:** `SC26RE_1k.fw` is the firmware to use. Also attached:
- `SC26RE_1k_capsense_dbg.fw`: raw stick/grip capsense values in the quaternion fields, for tuning.
- `SC26RE_1k_puck_dbg.fw`: Puck link counters in the quaternion fields.

**How to flash:** use the flasher in the report meter so that your pairings and settings survive. Close Steam first, connect by cable and keep "keep settings" ticked. The report meter is on the [SC2 1 kHz tools](https://pablo89898991.github.io/sc26re-1khz/) page; refresh it (Ctrl+F5) after updating.

## Changes since v47

Two new gyro options in **Live settings**, for anyone who wants to experiment. **Defaults are unchanged**, so the gyro behaves exactly like v47 unless you change them.

### Gyro range (full scale)
`250`, `500`, `1000` or **`2000` °/s (default)**. A lower range gives finer steps from the sensor, but turns faster than the range are cut off. The values Steam receives keep the same units, so sensitivity in games does not change.

Note: on this IMU the gyro noise does not depend on the range, and Steam's report format rounds the gyro to ~0.061 °/s per step anyway. In our test, 500 °/s did not lower the noise.

### Gyro averaging (in the controller)
**`1` = newest sample only (default)**, `2` = average of two sensor samples 0.5 ms apart (~0.25 ms more delay). The second sample needs an extra read on the IMU bus, so this mode currently loses about 4 % of the fresh samples.

### Measurements
Resting controller on a table, 5 s each, gyro peak-to-peak in °/s:

| Setting | Pitch | Yaw | Roll |
|---|---|---|---|
| Hardware filter 0, no averaging (raw) | 0.61 | 3.54 | 2.87 |
| **Hardware filter 1 (default)** | **0.37** | **2.63** | **1.95** |
| Hardware filter 0 + averaging 2 | 0.67 | 2.99 | 2.32 |
| Hardware filter 0 + averaging 2 + range 500 | 0.55 | 2.87 | 2.38 |

The sensor's own low-pass filter (setting 1) is the quietest, so it stays the default.
