Custom Steam Controller (2026) firmware with **1000 Hz** reports and the 1 kHz IMU path, based on Valve's latest stock firmware **6AE90BC5**.

**Download:** `SC26RE_1k.fw` is the firmware to use. Also attached:
- `SC26RE_1k_capsense_dbg.fw`: raw stick/grip capsense values in the quaternion fields, for tuning.
- `SC26RE_1k_puck_dbg.fw`: Puck link counters in the quaternion fields.

**How to flash:** use the flasher in the report meter so that your pairings and settings survive. Close Steam first, connect by cable and keep "keep settings" ticked. The report meter is on the [SC2 1 kHz tools](https://pablo89898991.github.io/sc26re-1khz/) page; refresh it (Ctrl+F5) after updating.

## Changes since v49

### Gyro as mouse: quick turns (flick)
Up to **4 quick turns**, each on its own button or touch sensor (same list as the activation: grips, stick touch, trackpad touch/click, triggers, back buttons…). Each turns the camera horizontally by **90°, 180°, 270° or 360°, left or right**, almost at once.
- **Angle:** taken from *counts per 360°*, so 180° is exactly half a turn in that game. Calibrate the game first, or enter Steam's Dots per 360.
- **Turn time:** how long the turn takes, default 60 ms (0 = in one report). A few tens of ms are safer, because some games dislike one huge mouse jump.
- **When it works:** whenever the gyro mouse is on, independent of the gyro activation button. The assigned buttons then belong to the gyro mouse and the game does not see them. With the gyro mouse off they work normally.
- Set it up in the meter: **Gyro as mouse → Quick turns (flick)**.

### Gyro as mouse: behaviour changes
- **Off after every power-on.** Turning it on with LB + RB + View (or in the meter) is no longer saved. All its other settings are saved as before.
- **Paused during any gyro calibration:** LB + RB + X + Y (both modes), the meter's *Full gyro calibration* and *Calibrate gyro*, and the automatic calibration. The cursor stays still while the gyro is measured, then the gyro mouse continues by itself.

### Steam Input values carry over
New box in the gyro mouse calibration section. Steam's **Angles to Mouse Pixels (Dots per 360°)** is the same number as *counts per 360°* here, and Steam's gyro multiplier is the same as the real world sensitivity here. Enter them and press **Use Steam values**, or **Show current as Steam values** to go the other way.

### Fixes
- **"default" for the capsense / gripsense thresholds now sticks.** The controller only reported the threshold in use (e.g. 900), so after reading, the meter unticked "default" and the next Save stored 900. It now also reports the user's setting, and the meter shows "default" with the value in use greyed.
- **Restoring settings after flashing could hang** at "restoring settings…": a background request to the controller that had just restarted never returned and blocked everything behind it. Requests now give up after 8 s.
- **The meter was sluggish:** too many background requests. Auto-refresh is now off by default (10 s when ticked, never overlapping), the status polls run every 2 s and pause in background tabs.
