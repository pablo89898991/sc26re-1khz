Custom Steam Controller (2026) firmware with **1000 Hz** reports and the 1 kHz IMU path, based on Valve's latest stock firmware **6AE90BC5**.

**Download:** `SC26RE_1k.fw`. `SC26RE_1k_puck_dbg.fw` is the same build with Puck link counters in the quaternion fields. Flash it with Ibex Web Utilities or `flash.py`. The report meter and the Puck patcher are on the [SC2 1 kHz tools](https://pablo89898991.github.io/sc26re-1khz/) page.

## Changes since v36

### Connection status LED (new, same as stock)
sc26re had no connection indicator, so the LED stayed solid even when the controller had lost the Puck. In wireless mode the LED now behaves like stock firmware:

- **Connected** to the Puck or a Bluetooth host: solid.
- **Not connected / searching**, e.g. after the Puck is unplugged from the PC: a slow blink every 2 s (fades in over 0.1 s, on 0.9 s, fades out over 0.1 s, off 0.9 s). It starts about 1 s after the link is lost.
- **Bluetooth pairing window** (RB + A + B at power-on): a quick double flash (on 75 ms, off 75 ms, on 75 ms, off 300 ms).

The blink only dims the current colour. Your colour set in Steam is kept, and the amber Puck charging light takes priority. Over the USB cable the LED does not blink.

All earlier changes are in the [v36](https://github.com/pablo89898991/sc26re-1khz/releases/tag/v36), [v35](https://github.com/pablo89898991/sc26re-1khz/releases/tag/v35), [v34](https://github.com/pablo89898991/sc26re-1khz/releases/tag/v34) and [v33](https://github.com/pablo89898991/sc26re-1khz/releases/tag/v33) releases.
