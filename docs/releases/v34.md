Custom Steam Controller (2026) firmware with **1000 Hz** reports and the 1 kHz IMU path, based on Valve's latest stock firmware **6AE90BC5**.

**Download:** `SC26RE_1k.fw`. `SC26RE_1k_puck_dbg.fw` is the same build with Puck link counters in the quaternion fields. Flash it with Ibex Web Utilities or `flash.py`. The report meter and the Puck patcher are on the [SC2 1 kHz tools](https://pablo89898991.github.io/sc26re-1khz/) page.

## Changes since v33

### Power-on / power-off sounds (new)
sc26re now plays the same power chimes on the grip actuators as stock firmware.

- **Power on:** a short pulse, then a rising chime of 588 → 699 → 882 Hz tones.
- **Power off:** a falling chime of 882 → 699 → 588 Hz tones.
  - It plays when you hold the Steam button, when Steam turns the controller off, on inactivity sleep, and when the USB cable is unplugged in wired mode.
  - The controller waits about 0.4 s for the chime to finish before it turns off.
- **No chime** after software restarts, such as switching between Puck and Bluetooth or a reboot requested by Steam. Lifting the controller off the Puck in charge-only mode also turns it off silently.
- **Volume** follows the stock setting `user/haptic_boot_level`: 0 = off, 1 = low (−18 dB), 2 = high (−12 dB, default). A value saved by stock firmware is imported, and Steam can read and change it like on stock. The feature can be turned off at build time with `CONFIG_IBEX_HAPTICS_POWER_SOUNDS=n`.

All changes from v27 to v33 are listed in the [v33 release](https://github.com/pablo89898991/sc26re-1khz/releases/tag/v33).
